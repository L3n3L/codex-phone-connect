# 手机遥控 Codex 滚动：需求

## 目标

手机只作为 Codex Desktop 的远程输入和滚动控制器。聊天内容继续显示在电脑 Codex 窗口中，手机不读取、不渲染聊天记录，也不接入 Codex Thread。

## 用户故事

- 作为手机用户，我可以在手机空白区域上滑或下滑，让电脑上的 Codex 聊天窗口滚动。
- 作为手机用户，我可以继续在底部输入框输入文字并发送给电脑上的 Codex。
- 作为电脑用户，我可以校准 Codex 聊天区域，让滚轮事件作用于正确的内容区域。

## 验收标准（EARS）

1. 当手机页面检测到一次超过最小阈值的垂直滑动时，Bridge 应向电脑 Codex 注入同方向的滚轮操作。
2. 当用户在手机上滑时，Codex 聊天区域应向下滚动；当用户在手机下滑时，Codex 聊天区域应向上滚动。
3. 当滑动距离过短或触点不在遥控区域时，Bridge 不应产生滚轮操作。
4. 当 Bridge 未完成聊天区域校准时，滚动请求应被拒绝并记录原因。
5. 当手机发送文字时，现有的输入框点击、剪贴板粘贴和发送按钮点击链路应保持可用。
6. 当发送和滚动请求同时到达时，Bridge 应按单线程队列顺序执行，不能并行注入鼠标或键盘事件。
7. 当 Codex 窗口不存在、不可见或无法激活时，Bridge 应拒绝滚动并记录失败，不应操作其他应用。
8. 手机页面不应返回聊天正文、截图、Thread ID 或 Codex 内部历史数据。

## 非目标

- 不实现聊天记录读取和手机端聊天渲染；
- 不实现 Thread 列表、会话切换和当前 Thread 识别；
- 不实现 Codex app-server 接入；
- 不实现全桌面远程控制；
- 不增加云端中继。
